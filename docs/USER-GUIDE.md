# User guide

## Mac

Download the Apple Silicon ZIP, extract it, and open the application. Read START-HERE.html for first-launch instructions. Keep the application bundle intact. No separate Python installation is required.

## Windows

Download the Windows x64 ZIP, right-click it and choose Extract All. Double-click FoulBrood GUI.exe in the extracted folder. Keep Resources beside it. No separate Python installation is required.

## Engines

The viewer does not include a playing engine. Download Mzinga or Nokamute for your operating system, extract all files together, then use Engine > Browse and Add & connect. Installed engines appear in the player choices and the analysis selector. Find engines searches common local folders; it does not install engines. Both engines have recognized game-review score formats.

## Play and analysis

Choose players and a time control to start a game. In Analysis, use Position for a single position or Game for review. Analyze also restores a suggestion you previously dismissed. Setup lets you rearrange a board, which discards its previous move history when applied. Engines that require history cannot analyze arbitrary setups.

White hints are gold and Black hints are blue. The History checkbox controls whether notation follows the board's flip and rotation. Auto toggles automatic fitting as the board grows.

## Game review and files

Game review compares the played move with the preferred move, displays position scores and depth, and ranks moves by their difference. Interrupted reviews can resume. Use Save review and Load review to preserve and restore the analysis in a PGN. Other compatible readers can still read its ordinary game moves.

Imports or resets may replace the current game, history and review. Read the warning before confirming. Games and reviews are held in memory until you explicitly save or export them; closing a browser is not a save operation.

Pause games and stop analysis before closing the browser. The local helper may remain running until sign-out or restart. One viewer tab per session avoids duplicate audio and competing controls.
